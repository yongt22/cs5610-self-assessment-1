About HTML

HTML, or HyperText Markup Language, is the standard language used to create and structure content on the web. Using a system of tags, like <p> for paragraphs, <img> for images, and <a> for links, HTML tells browsers how to display text, images, and other content on a page. Rather than handling logic or calculations like a programming language, HTML focuses on defining structure and meaning, forming the basic skeleton behind every website.

HTML rarely works alone, it pairs with CSS for styling and JavaScript for interactivity to create the websites we use every day. Its semantic structure also helps search engines understand page content and allows assistive technologies to support users with disabilities. Because of this, HTML remains the essential starting point for anyone learning web development or design.

About CSS

CSS, or Cascading Style Sheets, is the language used to control how a webpage looks and is laid out. While HTML defines the structure and content of a page, CSS handles the visual presentation, things like colors, fonts, spacing, and positioning. Using selectors and property-value pairs, such as color: blue; or font-size: 16px;, CSS lets developers target specific HTML elements and apply styles to them, either individually or across an entire site.

CSS gets its name from the "cascading" way styles are applied, rules can come from multiple sources, and more specific or later-declared rules can override earlier ones. Beyond basic styling, CSS also enables responsive design, allowing websites to adapt their layout for different screen sizes like phones, tablets, and desktops. Alongside HTML and JavaScript, CSS is one of the three core technologies of the web, and mastering it is essential for creating visually polished, user-friendly websites.

What I Learned

I learned about semantic elements like <header>, <nav>, <article>, and <footer>, and why using the right tag for the right purpose matters, not just for organizing content, but for accessibility and SEO as well. I also picked up on important concepts like the difference between block-level and inline elements, how attributes work within tags, and best practices for structuring forms, tables, and media elements properly. Overall, it helped me see HTML not just as a way to "make text appear on a page," but as a way to communicate meaning and structure to both browsers and users.

On the CSS side, MDN helped me understand how styling really works under the hood, especially concepts like the box model, specificity, and the cascade which explained a lot of confusing behavior I used to run into when styles didn't apply the way I expected. I learned how selectors, combinators, and pseudo-classes give fine-grained control over which elements get styled, and how layout systems like Flexbox and Grid make it much easier to build responsive designs compared to older methods like floats. By the end, I had a clearer picture of how HTML and CSS work together, HTML providing the structure, and CSS shaping how that structure is presented which has made me more confident about building clean, well-organized web pages.

When I Would Use Each Position

  • Relative: I would use relative positioning when I want to slightly move an element from its normal position or create a positioning reference for an absolute child.
  • Absolute: I would use absolute positioning when I want to place something at a specific location inside a positioned container like a notification badge.
  • Sticky: I would use sticky positioning for something that should remain visible after scrolling to it like a navigation bar or section heading.
  • Fixed: I would use fixed positioning when something should stay in the same place on the screen like a footer or floating help button.

Important HTML Head Elements for SEO

SEO, or Search Engine Optimization, helps search engines understand the content of a webpage and how it should appear in search results.

  • <title> - Defines the title of the webpage and helps search engines understand the page's topic.
  • <meta name="description"> - Provides a short description of the webpage that may be used in search results.
  • <meta name="robots"> - Tells search engines how they are allowed to crawl or index the webpage.
  • <link rel="canonical"> - Identifies the preferred URL when similar or duplicate versions of a page exist.
